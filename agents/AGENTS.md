# Agent instructions

## Comments

Most code needs no comment at all.

Never write:

- Code narration, provenance/history, evidence trails, ticket IDs as provenance, or meta-commentary on code shape.
- Restatements of docs, or section banners. Link to maintained docs instead.
- Never use the em dash "—". Use plain dash "-" instead

A comment states only the why that the code cannot carry. DO NOT leak our conversation, prompt, or iteration history into code comments, pull request descriptions, or other maintainer-facing prose. If and when you write comments, write them for readers who have not seen our conversation.

When writing commit messages, NEVER auto-add your agent name as co-author.
